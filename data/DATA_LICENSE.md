# Dataset licensing and attribution

The Time-MMD dataset documentation states that the Time-MMD database
is licensed under the Open Data Commons Attribution License (ODC-By)
v1.0:

https://opendatacommons.org/licenses/by/1.0/

The SENSA dataset revision is a corrected, aligned derivative assembled
from the numerical data distributed with MM-TSFlib and the fact/preds
fields distributed with SpecTF. It is not a byte-for-byte copy of the
current Time-MMD numerical files.

This notice documents the upstream dataset-level license and provenance.
It does not override any separate rights or source-specific terms that
may apply to individual text contents or other underlying material.
Redistributors must retain attribution to the relevant upstream sources
and comply with the terms applicable to those contents.

The SENSA authors' corrections and processing steps are summarized in
README.md in this directory. The SHA256SUMS file identifies the exact
released CSV files.

Before changing this repository to public, the maintainers should confirm
that redistribution of this combined corrected dataset is permitted by
all applicable upstream terms.
